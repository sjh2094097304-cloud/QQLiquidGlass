# QQ 液态玻璃定制版

版本：**0.4.2-qqdock.6**，versionCode 10。包名：io.github.liuran001.mmliquidglass。

## qqdock.6 变更

- 新增“底栏图标跟随 QQ 主题”开关。开启后，“仅图标 / 图标＋文字”会读取 QQ 当前主题或个性装扮的原生底栏图标；无法识别时自动回退模块线条图标。
- 主题图标通过小尺寸缓存位图同步，避免在悬浮底栏每帧直接重绘 QQ 原生 View；设置页实时预览会读取当前 QQ 主题图标快照。
- 保持左侧长按继续交给 QQ 原生逻辑，不改变现有液滴、玻璃、头像及频道标签顺序。

基于 [liuran001/WeChat-LiquidGlass](https://github.com/liuran001/WeChat-LiquidGlass)，基线提交 003d1a8d9c8d80fac4f3a63ef35835dc8d3a4e0e，保留上游 MIT LICENSE。此包是对话中的定制测试版，不是上游正式发布。

## 本次修改

用户确认 0.4.1 的底栏、头像和交互已经正常。本次主要扩展颜色与设置预览，延续已有的原生入口、头像点击、转场和采样限制。

- **自定义强调色**：在“外观 → 选中效果 → 强调色”选择“自定义”。支持色相、饱和度、明度滑条，以及 #RRGGBB / RRGGBB 输入；也接受 #RGB 简写。黑色和白色均有效。不完整输入保留上一个有效草稿颜色，不会覆盖成黑色。
- **可交互的真实光效预览**：顶部复用实际底栏的 LiquidGlassPanel、DropletPanel、DropletDragController 和标签绘制代码。可直接观察模糊、折射、色调、圆角、强调色和按压动效；点击标签切换、按住横拖液滴，或上下滑动示例背景。
- **更清晰的尺寸**：取消旧预览按 200dp 场景统一缩小的方式，栏体和字体按当前参数绘制。预览宽度与设置面板适配，短预览区会压缩悬浮距离的显示范围，界面明确标注。点“放大”可查看完整 0–100dp 悬浮范围；点“实时预览”标题可收起。
- **预览背景与头像**：可切换深／浅色、消息示例／彩色网格。标签来自当前 QQ 底栏；头像是打开设置时的当前模块头像缓存副本，未取得时用示意头像。消息、网格和数字未读角标是示例内容，不是 QQ 页面截图。
- **三项额外调节**：未选中标签不透明度 20–100%；选中底色跟随强调色；按压放大强度 0–125%。默认分别为 100%、关闭、100%，维持上一版外观与按压幅度。
- **预览与实际操作隔离**：预览只更新草稿，不会切换 QQ 页面或打开侧边栏；保存后才应用到首页。修改按显示帧合并，隐藏／关闭预览停止动画；十六进制输入唤起键盘时临时收起预览，给输入框留空间。预览采样不会覆盖实际 QQ 的背景接入诊断。

## 使用预览

1. 调节任意外观或布局参数，顶部预览会跟随草稿更新，无需反复保存。
2. 若要判断模糊、折射、饱和度，点击“消息”切成彩色网格背景；上下拖动背景能观察玻璃如何变化。
3. 若要判断按压高光、放大或动画速度，按住选中项并左右拖动；预览不会执行 QQ 的功能。
4. 选“自定义”后拖动颜色滑条或输入色值；输入完成后关闭键盘即可继续观察预览。“选中底色跟随强调色”打开后，底色也会着色。
5. 点“保存并应用”才修改 QQ 首页。关闭设置会放弃未保存草稿；原有头像和原生设置入口继续保留。

## 渲染边界

QQ 原生底栏的父级、宽高、padding 和监听器保持原位。液态玻璃只采样底栏之前的独立内容兄弟节点，并裁剪为底栏附近区域。胶囊、头像环和液滴共用背景显示列表，不分别重复绘制 QQ 内容；不把窗口、底栏自身或祖先容器作为采样源。

背景内容变脏才请求更新，玻璃自身重绘不会让内容节点变脏。采样有重入保护、暂停冻结和连续慢帧熔断。识别不到内容区、着色器不支持或采样异常时降级为蒙层并记录状态。暂停与销毁停止手势动画和异步头像工作。

此版 QQ 液态底栏要求 **Android 13 / API 33 以上**。更旧 Android 保留 QQ 原生底栏。微信继续使用原有安装及渲染路径，没有做微信真机回归。

## 保留的功能

头像继续读取 QQ 原生图片数据，兼容版本可使用独立 FaceDecoder 获取当前账号头像；不使用屏幕区域截图，不恢复此前将返回箭头误截为头像的路径。账号变化时清空旧缓存。

点击头像至多切换一次消息页、至多转发一次原生头像点击，保留防重入和有限等待。原生设置入口继续采用配置列表接入，不重新挂载 RecyclerView。日志区分“原生点击已转发”和“已确认侧边栏打开”。

| 内容与动效 | 未选中标签不透明度 20–100%；底色跟随强调色；按压放大强度 0–125% |
| 其他 | 隐藏原生底部背景；记录诊断日志 |

原版预设：4dp 模糊、24dp 折射、150% 饱和度、40% 蒙层。折射带会限制在中心区域之外，避免极端尺寸使着色器产生无效值。动画沿用上游弹簧，时长选项调节运行速度，不是精确完成时间；0 表示点击切页立即到位。

之前的尺寸、字号、显示模式和开关保留。0.4.0 的高不透明度按“旧值 × 40 / 86”换算为真实玻璃蒙层，保存后写入新配置；也可点击“原版”预设恢复光学默认值。

设置是独立深／浅色卡片面板，自绘开关不依赖 QQ 主题。修改保存在草稿里，保存才生效，关闭放弃未保存更改。顶部使用**实际玻璃渲染器＋示例背景**，支持草稿实时交互；宽度和悬浮位置适配预览区域，不能等同于整张 QQ 页面截图。深浅切换只用于预览，不修改 QQ 主题。

图标为模块线条图标，标签顺序和频道是否出现由 QQ 决定。仅可识别的数字 TextView 未读数会镜像，QQ 自绘的小红点不保证支持。

## 日志反馈

设置 → 反馈，可刷新、复制、导出 .txt 或清空本次日志。诊断包含模块／QQ 版本、Android API、接入状态、渲染降级原因、配置和模块事件。

日志只保存在内存，最多 160 条、每条最多 240 字符，相邻重复事件合并。异常只记录类型；不记录 QQ 号、昵称、聊天内容、图片或原始异常消息，并过滤长数字、邮箱和 URL。关闭记录并保存后停止新增事件，已有记录可清空。导出由系统文件选择器选择位置，没有自动上传。

## 安装与签名

1. 需要支持 **libxposed API 102** 的框架，并启用 QQ 作用域 com.tencent.mobileqq。
2. 与本对话提供的 0.3.x、0.4.0、0.4.1 定制包同签名，可覆盖安装。安装后**强制停止 QQ 再重新打开**，使新模块代码加载。

4. 长按右侧头像或进入 QQ 原生设置 → 液态玻璃；关闭头像或底栏后从原生设置进入。

## 构建与验证

使用 JDK 17、Android SDK 35 / build-tools 35.0.0、libxposed API 102.0.0。源码包已包含编译期 API jar，不会将其打进 APK。

设置 ANDROID_PLATFORM_JAR 和 ANDROID_BUILD_TOOLS 为实际 SDK 路径后，运行 bash build.sh。运行 bash tests/run.sh 执行回归检查。

构建经过 javac、D8、aapt2、zipalign、apksigner。检查包括 1518 项原有几何断言、32911 项配置／几何断言、14175 项颜色／草稿／预览位置断言、工作合并／点击令牌／日志测试，以及实际手势控制器和共享背景类的主机端测试。后两组使用明确的 Android 测试替身，覆盖按住放大、拖动松手、取消不切页、停止帧回调、共享缓存、重入保护、暂停和异常释放；**不模拟 GPU 或真实 QQ View**。

用户已确认上一版在其 QQ 上正常；此版仍没有目标设备或 QQ 运行实例可供开发侧测试。新增颜色编辑器、实时预览的 GPU 画面、最终尺寸和键盘排版尚未在 QQ 9.2.75 (13520) / Android 16 API 36 真机验证。

本次真机复测重点：自定义颜色保存／重开后保留，关闭草稿不影响首页；预览模糊、折射及按压动效能即时变化；深浅背景、放大／收起和键盘布局正常；预览操作不切换 QQ 页面。之前已经正常的头像、入口和聊天转场应保持正常。
