# 回归验证

```bash
python3 tests/run_regression.py
python3 tests/run_api_check.py
```

需要 JDK 17 与 Python 3.9+；两条命令均可离线运行。输出写入 `build/`，测试与桩代码不进入 APK。

`run_regression.py` 编译并执行真实生产类的配置、JSON、随机、过滤及协议处理逻辑。SharedPreferences 测试实现模拟 Android 的关键行为：`commit()` 返回 false 时，进程内 map 已经变化，磁盘保留旧值。Provider 也模拟不可用、延迟、恢复、提交失败和调用者校验。

覆盖 13 组场景：

1. 防撤回混合同步包保留普通消息与未知字段；已知自身私聊路由、异常包边界。
2. 使用 Android 原版 `org.json` 校验导入，覆盖非法结构/类型、整数溢出、深度、上限和转义。
3. 随机池哈希碰撞、120 轮完整去重、单 ID 池、固定转随机及过期统计。
4. 当前消息 ID、默认 0/115、表情、贴纸、正文伪 ID、转发记录。
5. 商城类型前缀、数字边界、编码、冲突参数、裸 ID 不抢占真实资源。
6. QQ 菜单值相等时的身份区分，日志去重期限与容量上限。
7. 删除当前固定 ID、提交失败回滚、真实读写探针、Provider 调用者权限。
8. Provider 离线、恢复、失败重试、重启持久化；ID-only 导入不关闭防撤回。
9. 3.6 配置迁移、相同快照不重复落盘、并发写入期间拒绝旧镜像。
10. 发送不续期、过期刷新、配置快照不可被调用方改写。
11. 错误包不覆盖有效缓存，失败写入恢复原状态。
12. 慢 Provider 期间首次和后续发送读取都不等待 IPC；旧异步结果不覆盖新操作。
13. 自检必须逐项证明 Hook 已安装，设置入口不能代替发送能力。

`run_api_check.py` 对全部应用 Java 进行裁剪接口桩编译，不是真实 Android SDK、DEX 或 APK 构建。说明见 `api_stubs/README.md`。

测试没有运行 QQ、FPA/LSPosed、Android 真机或模拟器，不能据此声称所有框架均兼容或流畅度提升了某个百分比。
